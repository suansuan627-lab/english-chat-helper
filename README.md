# 言外 · 英语聊天助手

用于微信聊天的自然英语表达工具，适配手机和电脑。

## 当前进度：示例体验版

已完成页面、语气选择、预置例句、歧义澄清示例和英文复制。
**尚未接入 AI。不能翻译任意输入，也没有实时语义复核。**
当前内容是人工预置示例，不是 AI 实时输出；修改原文或补充背景后，不会套用旧译文。
切换语气或修改输入会清除旧结果，避免误复制。

输入只停留在当前页面，不上传、不保存到浏览器存储；刷新页面会丢失。
网站无法读取微信私人聊天，也不会自动发送消息。

## 第一步：发布体验网页（不需要安装软件）

1. 在本仓库点击 **Settings**。
2. 在左侧找到 **Pages**。
3. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
4. 在 **Branch** 选择 **main**，目录选择 **/ (root)**，点击 **Save**。
5. 等待 GitHub 完成部署，刷新 Pages 页面，使用页面显示的 **Visit site** 链接打开网站。

预计地址：https://suansuan627-lab.github.io/english-chat-helper/
只有 Pages 部署成功后，这个地址才可访问。

## 第二步：体验

1. 点击“稍晚一点到”或“礼貌拒绝”。
2. 选择表达语气，点击“查看示例表达”。
3. 核对英文下方的中文意思，再点击“复制英文”。
4. 回到微信，粘贴到输入框，确认后自行发送。
5. 点击“一句有歧义的话”，体验先澄清再表达的流程。

自动复制需要浏览器支持并允许剪贴板访问，失败时可手动复制。

## 下一阶段：真实翻译

需要选择模型服务并部署安全的后端，再接入当前网页。
模型 API 密钥必须保存在服务端，不能提交到 GitHub 或写入网页 JavaScript。
后端需包括访问控制、调用限额、超时处理和语义核对流程。
接入前应明确告知用户哪些输入会发给模型服务。
任何 AI 模型或复核流程都不能保证零误译，不能以回译一致证明翻译绝对正确。

## 本地预览（由开发助手操作即可）

安装 Node.js 后运行 `node preview.cjs`，打开 http://127.0.0.1:4173 。
网站本身是纯 HTML / CSS / JavaScript，无需构建，无外部依赖或第三方字体。

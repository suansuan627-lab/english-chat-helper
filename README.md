# 言外 · 英语聊天助手 v2

面向微信聊天的中译英网页，手机和电脑可用。由 GitHub Pages 托管界面，通过个人 Cloudflare Worker 调用 DeepSeek。

## 当前状态（2026-10-26）

- v2 前端已实现真实接口调用、访问口令、数据发送同意、语气、背景、澄清提示、模型复核结果、复制、取消、超时和错误处理。
- 27 项本地模拟测试通过；它们验证功能和失败处理，不证明真实翻译质量。
- GitHub 线上此前发布的是示例版，需上传本版文件后等待 Pages 部署。
- 后端 v1.1 配置检查已通过，未认证请求返回 401，口令保护生效；此前口令长度问题已解决。尚未验证真实模型密钥有效性、余额和翻译质量，需网页更新后由用户输入访问口令联调。

## 使用

1. 在网页填写 Cloudflare 中的 APP_PASSWORD，不是模型 API 密钥。
2. 输入中文和必要的聊天背景，选择语气。
3. 阅读并勾选数据发送说明，点击“翻译并核对原意”。
4. 若提示澄清，在聊天背景补充答案，再次提交；不自动选择含义。
5. 核对结果后复制英文，回到微信自行粘贴发送。

每次正常翻译包含两次模型调用，首轮需要澄清则一次。取消等待不保证模型调用不计费。程序不自动重试收费请求。
输入修改或取消将使旧请求失效，复核失败不显示草稿，服务失败不会回退到假示例。

## 隐私和配置

消息和背景经 Cloudflare 发送给 DeepSeek，网页不主动持久化聊天记录和口令。供应商自己的数据政策仍然适用。
模型密钥只配置在 Cloudflare Secret 中。源代码和上传包都不应包含真实密钥/口令。
APP_PASSWORD 是个人访问凭据，不可共享；网站无全球硬性费用上限。CORS 不是认证。
无法读取微信聊天，也不会自动发送消息；模型复核、中文释义均可能出错，不保证零误译。

后端配置和接口见 backend/部署说明.md。后端已采用手工部署方式，不会随前端 GitHub 上传自动更新。
